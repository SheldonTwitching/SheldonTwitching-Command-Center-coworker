# SheldonTwitching Labels — v1.0 Streamlabs goal styling and arcade stream scenes

A private, Twitch-specific Windows label designer using SheldonTwitching's purple, neon magenta and arcade-cabinet style. **No SheldonTwitching Labels cloud account or Streamlabs login required.** Spotify playback requires the owner to configure Spotify OAuth locally. Your Streamlabs Streamlabels desktop app must be configured to write text files to a folder for live data.

## Quick start

**Normal Windows desktop usage**

1. Download this project and extract it somewhere permanent.
2. Install [Python for Windows](https://www.python.org/downloads/windows/) 3.11+ (select **Add Python to PATH**).
3. Double-click **`Build-Windows-EXE.bat`**. This downloads Windows dependencies and builds **`dist\SheldonTwitching Labels.exe`**. First build requires internet access. There is no prebuilt executable in this archive.
4. Double-click the new EXE. A desktop editor opens. Closing its window **hides it to the notification tray** while the OBS bridge stays live. To stop the bridge, right-click the tray icon → **Exit — stop OBS bridge**. The tray icon requires the dependencies included in the built EXE.
5. Optional: turn on **Start with Windows** in the editor toolbar to launch the OBS bridge automatically at sign-in (no administrator rights required).
6. In the editor, press **Browse** to choose the folder where Streamlabels writes its `.txt` files. Alternatively, paste the folder path and press **Connect folder**.
7. Select a label; pick an existing `.txt` file, import an icon or set an emoji, adjust sliders, drag/resize in preview, select an arcade preset, or enter raw CSS. Click **Preview rotation** to play through the sequence.
8. In OBS Studio, add **Browser Source** with URL **`http://127.0.0.1:47831/overlay`**. Match its width and height to the canvas settings shown in the editor (default **900 × 180**). To avoid unnecessary reloading, uncheck **Shutdown source when not visible**. Keep the bridge running while streaming.
9. You can also choose **Export Overlay ZIP**. Its extracted `overlay.html` includes your current design and remains dependent on the bridge for live `.txt` updates. The local OBS URL is the recommended option because visual changes appear automatically without re-export.

**Run without building:** `Run-Editor.bat` or `py app.py`. Install desktop dependencies with `py -m pip install -r requirements-windows.txt` for the tray/window experience. Without these, the editor opens in the default browser and closing the script stops the bridge.

**Start just the tray bridge for OBS:** `Start-Bridge.bat`, or run `"dist\SheldonTwitching Labels.exe" --headless`. Do not use a second copy of the bridge: the launcher reuses an already running bridge on the same port.

## How the editor works

- **Visual editor:** Select a follower, subscriber, donor or another label; duplicate, reorder, add, and drag. Size and font sliders, border/background colors, opacity and glow update live.
- **Starter styles:** Arcade Neon, Flame, Minimal, and Glass. These apply only to the selected label, retaining its data source and animations.
- **Data panel:** Choose a source `.txt` file; raw, split, before-colon, currency, or regular-expression extraction; prefix/suffix and fallback. Click a file on the left to reassign without losing styling.
- **Motion panel:** Entrance and exit animations, duration, hold time, enable/disable, and rotation order.
- **CSS panel:** Raw CSS for advanced editing, imported from files if needed. Raw CSS is layered **after** the visual styles so the resulting rendered values can override slider values. Examples: `.overlay-card { background: transparent; border:0; }` or `.overlay-value { letter-spacing:2px; }`. Changes update OBS automatically.
- **Project:** Autosaves to `%APPDATA%\SheldonTwitchingLabels\project.json`; previous version kept as `.bak`. Download your editable `.json` project, or import it later. Undo/redo buttons (Ctrl+Z / Ctrl+Y outside text inputs) are provided.
- **OBS URL:** `http://127.0.0.1:47831/overlay`, live project and Streamlabels data. Click **Copy OBS URL** in the application.

## Technical details

All HTTP requests are served locally on `127.0.0.1`, no external server. The data bridge polls up to 250 direct `.txt` files in the chosen folder; text is safely read as UTF-8 or Windows-1252 fallback, up to 64 KB per file, and updated to OBS about once a second. The visual editor and OBS use one browser rendering engine (`web/renderer.js`) and its scoped styles. Icons are embedded into the project, so files are portable; imported images are capped at 400 KB. Live overlays are **not** magically standalone: keep this application's bridge running, and keep Streamlabs Streamlabels running to write new data.

The ZIP contains **source code plus Windows EXE build scripts**, not a precompiled and Windows-tested installer. A Windows machine with a working Python/PyInstaller installation is required to compile and verify the EXE. Older Windows installations may require the Microsoft WebView2 runtime. `Start-Bridge.bat` can launch the bridge without showing the editor. A Windows build workflow is included in `.github/workflows/windows-build.yml` if you prefer a CI-compiled executable.

## Troubleshooting

- **Only fallback text in OBS:** Make sure Streamlabels is exporting `.txt` files and its folder is connected in the editor. Check the filename in Data for the currently selected item.
- **Empty OBS browser source:** Check the bridge is running (Windows notification tray) and open the URL in your browser. Confirm your OBS Browser Source dimensions match the canvas values.
- **Editor disappears after closing:** It is hidden in the tray on purpose to keep OBS updating. Double-click launcher again or use the tray menu → Open designer.
- **Styles not updating:** The live URL will update after autosave; exported local HTML snapshots will not automatically take new styles. Prefer the URL.
- **Need to move to another PC:** Use **Project** download; move your label text files and connect the new folder location when importing.

**Scope:** for one personal Twitch stream, not an account-based platform. This is an active v0.8 development build. The Windows EXE, Spotify account connection, real tip bar file mappings, and OBS Studio still require live testing on the owner’s machine.
