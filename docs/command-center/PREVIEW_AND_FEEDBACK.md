# Pop-out previews and screenshot feedback

Use **Pop out preview** beside the scene, cabinet or controller preview, **Pop out label preview** in Labels, or the pop-out buttons beside individual source entries under Setup & Sources. **Pop out editor** opens the current embedded editor in a larger separate window. Desktop pop-outs are separate resizable app windows; browser use opens a separate window/tab when pop-ups are allowed.

The preview keeps its source URL when opened so several sources can be compared. Saved edits remain live through the shared local bridge. Use **Open editor** to adjust it alongside the preview, **Fit window**, **100% native**,25-400% zoom, scrolling, background checks, fullscreen and refresh. These controls affect the inspection window only; they do not resize source artwork or change OBS transforms. Pop-outs can be closed without stopping the bridge.

For feedback, capture the preview plus any relevant settings. Include the app build, scene/widget name, source URL path, preset, OBS size/zoom, expected result and what happened. Add notes under Widget Roadmaps and use Export Studio if you want to send the saved project too. Attach screenshots and notes in this chat; do not include tokens or private Streamlabs URLs.
