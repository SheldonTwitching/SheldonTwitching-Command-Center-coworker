# Six-stage art production prompts

Use arcade/stage-registry.json for the six exact stage IDs, briefs, existing asset paths and missing layers. Three base backgrounds exist; three slots require art. No new images are generated by this organization pass.

## Shared brief for every image model

Create a detailed pixel-art fighting-game stage inspired by [REGISTERED BANGOR LOCATION]. Match the approved arcade reference: dark indigo shadows, glacier cyan and violet, restrained magenta graffiti, deliberate pixel clusters, controlled dithering and hard pixel edges. Fixed wide camera, level fighting floor and consistent horizon/perspective. Canvas 1920×1080; declare logical pixel scale before production and keep it identical across all layers. No smooth vector gradients, photographic textures, typography, logos, people, fighters, HUD, borders or watermarks.

Reserve unobstructed fight-floor and broadcast safe regions specified in the stage brief. Provide separate registered layers: sky, far clouds, skyline, near clouds, background structures, fight floor, foreground, emission, light receivers, occlusion, reflections and weather. Layer bounds, anchors and camera must match. Do not claim one flat composite supplies independent masks. Original approved assets remain untouched.

## Location briefs

Populate the registered Rooftop Circuit, Bangor Neon Waterfront, After Hours, Downtown Neon Alley, Bridge Underpass and Mill District slots using their manifest briefs. Verify exact manifest titles/IDs when authoring; location names are art inspiration, not claims of precise real-world building geometry. Keep all six cohesive while giving each distinct silhouettes, material textures and one music focal fixture.

## Time and weather variants

Using the SAME reference geometry, camera, floor and pixel density, author [morning/day/dusk/night] and [clear/cloudy/rain/snow/fog/storm] layers. Change only the specified light/weather/material responses. Overhangs cast consistent shadows; emission illuminates registered receivers; occluders block light; wet surfaces receive bounded reflections. Do not randomly move buildings or alter the fight floor between variants.

## Loop sheets

Author [cloud/river/vent/rain/foreground] sprites on transparency with explicit frame bounds, pivots, frame count and durations. Loop playback at 24, 30 or 60 fps, default 30. First/last motion must join seamlessly; unique drawn-frame count is separate from playback cadence. Preserve silhouette/palette without frame-to-frame flicker. Output sprite-sheet layout and timing metadata as separate deliverables, verified against actual pixels.

## Audio layer

Author a separate emission mask for [REGISTERED FOCAL FIXTURE], a receiver mask on adjacent physical surfaces, occlusion and optional reflection masks. Keep a crisp unlit base. Runtime audio changes intensity through these layers; never repaint or flash the entire background to simulate sound.

## Review gate

Compare against source at native and enlarged nearest-neighbor scales; inspect alpha, layer alignment, 24/30/60 cadence and seam closure. Reuse the same stage assets in Starting Soon fights, BRB, Outro and full-screen backgrounds. Record approved asset hashes, generation prompt/model, dimensions, pixel scale, pivots, mask roles and frame timing before enabling the asset in the registry.
